## 2.1 クラウドインフラストラクチャー

### 2.1.1 さくらのクラウドの全体像

- さくらのクラウドは **パブリッククラウド（IaaS）基盤**。
- 構成要素: **データセンター設備** の上に **クラウドインフラストラクチャー（サーバ／ストレージ／ネットワーク）** を提供。
- **2011年11月** にサービス提供を開始。

### パブリッククラウドが備える特長（NIST定義の5特性）

1. オンデマンド・セルフサービス
2. 幅広いネットワークアクセス
3. リソースの共用
4. スピーディな拡張性
5. サービスが計測可能

> NISTによるクラウドコンピューティングの定義（情報処理推進機構の日本語版）が参考資料として示されている。

### さくらのクラウドの特長（一般的なパブリッククラウドに「加えて」備える点）

| 特長 | 内容 |
|------|------|
| 物理的に離れた場所を使い分ける構成 | **国内2カ所のリージョン**（石狩・東京）を使い分け可能 |
| 費用の最小化 | **データ転送量による従量課金なし**。サーバ／ストレージ等のリソースは**利用時間に合わせて一番安い料金が適用** |
| 直感的な操作＋IaC | 直感的なコントロールパネル、IaCを実現するAPI、コマンドラインツール、**Terraform for さくらのクラウド** に対応 |
| 他サービスとの連携に強い | ハイブリッド接続対応。専用サーバ・ハウジング・リモートハウジングと連携可能 |

- コントロールパネル: ウェブブラウザから様々なリソースに加え、**料金・契約リソース・APIキー・ログ** を確認できる。
- コマンドラインツールがあればブラウザを使わずに操作可能。
- Terraformは様々なクラウドのIaCに対応している。

### リージョン・ゾーン・ネットワーク用語（重要）

| 用語 | 定義 |
|------|------|
| データセンタ | 地理的な単位。専用サーバは石狩(北海道)、ハウジングは東新宿・西新宿・代官山 |
| リージョン | さくらのクラウドにおけるデータセンターの地理的な単位。**石狩リージョン（北海道）または東京リージョン** を選択。複数リージョンを利用可能 |
| ゾーン | リージョン内のネットワーク管理単位。各ゾーンは**物理的に独立**。**石狩第1・第2・第3ゾーン、東京第1・第2ゾーン** を選択 |

- **ブリッジ接続**: 異なるゾーン間をローカルネットワーク(L2)で接続。
- **ハイブリッド接続**: 異なるゾーン間やサービス間をローカルネットワーク(L2)で接続。**ブリッジ接続よりも接続可能なサービスが多い**（専用サーバ・ハウジング等とも接続）。

### ネットワークの構成種別

| 種別 | 特徴 |
|------|------|
| 共有セグメント | 共有ネットワーク。**1つのグローバルIPアドレスが付与** |
| 専用セグメント | 専用グローバルネットワーク。**ネットワーク単位でグローバルIPアドレスが付与**（ルータ＋スイッチ、/28 - /24）、パケットフィルタ |

- グローバルに接続しないサーバ（ローカルネットワークのみ）も設定可能。

### さくらのクラウドが備える様々な機能（カテゴリ別一覧）

サーバ／ディスク以外にも各種リソースを利用できる。

| カテゴリ | 主な機能 |

| ネットワーク | スイッチ／ルータ＋スイッチ、VPNルータ機能、ブリッジ接続（ゾーン間接続）、ハウジングや専用サーバとも連携 |

| パターン | 内容 |
|----------|------|

| クラウドも専用サーバも使いたい | クラウドのスケール能力と物理サーバの高性能を組み合わせる |

### 2.1.2 GPU・コンテナ系サービス（クラウドインフラ内）

| サービス | 種別 | 概要 |
|----------|------|------|
| **AppRun** | コンテナ実行 | コンテナ化されたアプリを簡単にデプロイし、自動的にスケーリングするサービス。開発スピード向上／インフラ管理からの開放／自動スケーリング／統一された開発環境 |
| **高火力DOK** | コンテナ型クラウドサービス | **NVIDIAのGPUを使用してDockerイメージを実行** |
| **高火力VRT** | VM（仮想マシン）型のGPUクラウドサービス | さくらのクラウドとシームレスに接続 |

> AppRunの4つの価値: 開発スピードの向上 / インフラ管理からの開放 / 自動的なスケーリング（トラフィックに応じてリソースを自動増減）/ 統一された開発環境（本番と開発の環境差をなくす）。

### 2.1.3 さくらのVPS

- **VPS = Virtual Private Server** の略称。一般に「仮想サーバ」「仮想プライベートサーバ」と呼ばれる。
- 特徴:
  - 仮想化技術を使い、仮想サーバを利用するサービス。
  - ミドルウェアやアプリケーションは**自分で管理する**。
  - クラウドのような**スケールアウトはできない**。
  - **スケールアップはコントロールパネル上から簡単に可能**。
  - ローカルエリアネットワーク間の接続ができる。ネットワーク設定に特殊な仕様はない。

### パブリッククラウドとVPSの違い（重要）

| 項目 | VPSの仮想サーバ | クラウドの仮想サーバ |
|------|-----------------|----------------------|
| 仮想化技術 | 使う | 使う |
| クラウドの要件 | **満たさない** | **満たし、可用性が大きい** |
| 物理障害時の挙動 | 物理サーバに障害が発生すると、その上の仮想サーバも**停止する** | 物理サーバに障害が発生しても、**正常な物理サーバ上でただちに復帰できる** |

> ⚠️ 試験頻出: VPSとクラウドの本質的な違いは**可用性**。VPSは物理サーバ障害で仮想サーバが停止するが、クラウドは別の正常な物理サーバ上で即時復帰できる。

## 2.2 クラウドアプリケーション（さくらのレンタルサーバ）

- さくらインターネットは**さくらのレンタルサーバ**をクラウドアプリケーションとして提供。
- 基本特性: **月額単位の課金／共用環境／管理者権限不要**。
- 利用するオプションによっては追加費用が必要になる場合がある。

### さくらのレンタルサーバが提供する機能（カテゴリ別）

| カテゴリ | 機能 |
|----------|------|
| ウェブサイト制作・公開 | クイックインストール、Webフォント |
| サーバー設定 | コンテンツブースト（CDN機能）、バックアップ＆ステージング、ドメイン設定、MySQL、モニタリングツール |
| メール送受信 | ウェブメール、メーリングリスト、メール転送、メール自動返信、迷惑メールフィルタ |
| セキュリティ | SSL、Web改ざん通知サービス、WAF、国外IPアクセスフィルタ |

### クラウドインフラストラクチャーとクラウドアプリケーションの比較（最重要表）

※ページ図を視覚確認し、3行構成（クラウドインフラ／さくらのVPS／クラウドアプリケーション）を反映。

| 項目 | クラウドインフラストラクチャー | さくらのVPS | クラウドアプリケーション |
|------|:---:|:---:|:---:|
| 管理者権限 | ○ | ○ | × |
| コントロールパネル | ○ | ○ | × |
| 提供形態 | 専用 | 専用 | 共用 |
| 料金体系 | **時間割日割り または 月額料金** | 月額料金 | 月額料金 |
| API | ○ | × | × |

> ※利用するサービスやオプションによっては異なる場合があります。
> ⚠️ 試験頻出: クラウドアプリケーション（レンタルサーバ）は **管理者権限なし・コントロールパネルなし・APIなし・共用・月額料金**。クラウドインフラは**専用・時間割日割り/月額・APIあり**。VPSは**専用・月額・APIなし**。

## 2.3 物理基盤サービス

### ハウジング

- データセンター内のラックに、サーバやネットワーク機器を収容するサービス。
- 特徴: **入局可能／回線選択可能**。
- データセンター: **石狩・堂島・東新宿・西新宿・代官山**。

### さくらの専用サーバPHY

- **クラウドの使い勝手を備えた専用ホスティングサービス**。
- コントロールパネルを通した設定や契約が可能。
- 契約の追加、OSインストール、ネットワークインターフェースの冗長構成、ローカルネットワークも構成できる。
- 物理サーバの専用ホスティングでありながら、**クラウドのような使い勝手と高性能を両立**。

### GPUベアメタルサーバー 高火力PHY

- 専用サーバPHYと同様に、クラウドの使い勝手を備えた専用ホスティングサービス（コントロールパネル設定・契約、契約追加・OSインストール・NW冗長構成・ローカルネットワーク構成可、使い勝手と高性能を両立）。
- 対応GPU: **NVIDIA H100 / H200 / B200**。

> ⚠️ 試験頻出: GPUの対応モデルで区別。**高火力PHYは H100/H200/B200**（B200・H200に対応するのはPHYのみ）。高火力DOK/VRTはH100/V100（アドバンスド教材より、本資料には明記なし ※要確認）。

## 2.4 さくらのクラウドの周辺サービス

### さくらのドメイン

- 各種ドメイン名の**取得・更新**、ネームサーバ運用。
- 対応TLD例: `.jp` `.com` `.net` `.org` `.biz` `.info` `.tokyo` `.mobi` `.co.jp` `.or.jp` `.ne.jp` `.gr.jp`。
- ネームサーバ設定の運用形態: **DNSアプライアンス**（自動）または**手動運用**。

### さくらのSSL

利用シーン（用途）で証明書を選ぶ。

| 利用シーン | 想定される証明書の特徴 |
|------------|------------------------|
| ECサイトで決済情報を扱う | 信頼性を重視 |
| 企業サイト | 信頼性をアピールし安心を提供 |
| スピード重視 | 即日発行 |
| 複数サブドメインを管理 | 1枚の証明書で複数サブドメインを管理（ワイルドカード） |

### ImageFlux

- **画像変換・配信エンジン**。
- 1枚の画像から各デバイスに最適化された画像を生成し、**高速かつ高品質で配信**。

### さくらのIoT

- **さくらのモノプラットフォーム**
- **さくらのセキュアモバイルコネクト**

### マーケットプレイス

- さくらのクラウドで申し込み可能／さくらインターネット動作検証済み／**ライセンス自動課金**。
- 提供カテゴリ:

| カテゴリ | 内容 |
|----------|------|
| セキュリティサービス | 脆弱性の脅威・攻撃からサーバを保護し、不正アクセスや情報漏えいに備える |
| バックアップサービス | 複数のバックアップを一括管理、さまざまなプランを選べる |
| 監視サービス | ネットワーク・サーバー・アプリケーションの稼働を一元的に監視 |
| その他・アプリケーション | CMS・データ変換など日頃のサイト運用の手間を軽減 |

### 脆弱性診断サービス

| サービス | 内容 |
|----------|------|
| WebSite Scouter（Web脆弱性診断） | Webサイトのリモート診断、Web管理画面からのスケジュール実行 |
| ネットワーク診断サービス | ネットワーク・OS・ミドルウェアのリモート診断、**CVSS / CVEに準拠**、Web管理画面からのスケジュール実行 |

### プレミアムサポート

- **24時間365日、日本国内の専門スタッフが支える「いつでもつながる安心」の有償サポート**。

| 項目 | プレミアムサポート | スタンダードサポート |
|------|--------------------|----------------------|
| 対象 | プレミアムサポート加入者 | すべてのクラウド利用者 |
| 電話問い合わせ | **フリーコール** | コールバック（予約制） |
| メール問い合わせ | さくらのクラウドホームで受付 | 会員メニューより受付 |
| 対応時間 | **24時間365日** | 平日10:00～18:00 |
| 月額料金 | **有償**（クラウド利用料に応じた階段式 ※年2回の価格見直し有） | 無償 |
| 初回回答時間 | 仕様/コンパネ操作：8h以内 / 障害の確認：2h以内 | 当日または翌営業日中（仕様/コンパネ操作・障害の確認・契約/料金の問合わせ） |

> ※サポートの対象は責任分界点におけるさくらインターネットの担当範囲となる。

## 3. 試験対策・要点チェック

- [ ] さくらのクラウドは **2011年11月** にサービス開始、**パブリッククラウド(IaaS)基盤**。
- [ ] パブリッククラウドの5特性 = オンデマンド・セルフサービス / 幅広いNWアクセス / リソースの共用 / スピーディな拡張性 / 計測可能（NIST定義）。
- [ ] さくらのクラウド独自の特長 = **データ転送量の従量課金なし**、**国内2リージョン（石狩・東京）使い分け**、利用時間に応じた最安料金、Terraform/API対応。
- [ ] リージョン=地理的単位（石狩・東京）、ゾーン=物理的に独立したNW管理単位（石狩第1/2/3・東京第1/2）。
- [ ] **ブリッジ接続**＜**ハイブリッド接続**（ハイブリッドの方が接続可能サービスが多い）。
- [ ] 共有セグメント=グローバルIP1つ、専用セグメント=NW単位でグローバルIP付与（/28-/24）。
- [ ] 高火力DOK=GPUでDockerイメージ実行（コンテナ型）、高火力VRT=VM型GPU、高火力PHY=GPUベアメタル（**H100/H200/B200**）。
- [ ] AppRun=コンテナアプリを簡単デプロイ＆自動スケーリング。
- [ ] VPS = Virtual Private Server。**スケールアウト不可・スケールアップはコンパネで可能**、ミドルウェア/アプリは自己管理。
- [ ] VPSとクラウドの違い＝**可用性**。VPSは物理障害で停止、クラウドは別物理サーバで即時復帰。
- [ ] レンタルサーバ（クラウドアプリ）= **月額課金・共用・管理者権限不要・APIなし・コンパネなし**。
- [ ] 3区分比較: クラウドインフラ（専用・時間割日割り/月額・API○）/ VPS（専用・月額・API×）/ クラウドアプリ（共用・月額・API×・管理者権限×・コンパネ×）。
- [ ] 物理基盤=ハウジング（石狩・堂島・東新宿・西新宿・代官山）/ 専用サーバPHY / 高火力PHY。
- [ ] 周辺サービス6種 = ドメイン / SSL / ImageFlux（画像変換・配信）/ IoT（モノプラットフォーム・セキュアモバイルコネクト）/ マーケットプレイス（ライセンス自動課金）/ プレミアムサポート。
- [ ] ネットワーク脆弱性診断は **CVSS/CVEに準拠**。
- [ ] プレミアムサポート = **24時間365日・有償（階段式）・フリーコール**、初回回答 仕様/操作8h・障害2h。スタンダードは無償・平日10-18時。
