## 1. エンハンスドロードバランサ

### 概要
- **HTTP/HTTPSに特化したプロキシ型ロードバランサ**（TCPでのバランシングも可能）。
- **L7ロードバランサ**であり、**可用性と耐障害性の向上**に用いる。
- **グローバルリソース**（リージョンに依存せず作成可能）。

### 提供プラン（重要）
- **処理性能に応じたプラン**を選択。
- 性能指標は **CPS（Connection per second：1秒あたりの新規接続可能数）**。
- **プラン名がHTTP/TCPでのCPSの上限を表す**。
  - **最小: 100cpsプラン / 最大: 400,000cpsプラン**。
- ⚠️ **HTTPSの場合、CPS性能はプラン名の10分の1**となる。
- 各プランで設置先を選択可能: **固定（東京/石狩リージョン）** または **自動（エニーキャスト）**。

### 料金
- プランと設置先に応じた **時間額・日額・月額** が設定されている。

### 基本仕様（重要表）

| 項目 | 仕様 |
|------|------|
| ネットワーク構成方式 | プロキシ方式 |
| ロードバランシング可能なプロトコル | HTTP、HTTPS、WebSocket(ws,wss)、TCP ※ |
| 冗長化 | 標準で冗長構成（拠点内で複数台構成） |
| 設定可能な実サーバ数 | **1台あたり最大40台** |
| 振り分けアルゴリズム | **least connection** |
| IPv6対応 | **非対応** |

> ※ TCPを選択した場合、**L7関連機能は利用できない**。

### 通信フロー（プロキシ方式）
1. クライアントは、払い出された **VIP** と、利用者が設定した待ち受けプロトコル・ポート番号宛てに通信。
2. エンハンスドロードバランサが **いずれか1台の実サーバに転送**。
3. 実サーバからのレスポンスは **エンハンスドロードバランサを経由して** クライアントに返る。

### 利用開始までのステップ
1. エンハンスドロードバランサの作成
2. 待ち受けプロトコルとポートの設定
3. 実サーバの登録

## 2. エンハンスドロードバランサの作成

### 作成時の主な設定
- プランの選択 / 設置先の選択 / **VIPフェイルオーバ機能の有効・無効** / ヘルスチェックの設定。
- 作成後、接続先となる **VIP** が表示される。
- ヘルスチェック等でLBが実サーバに接続する際の **接続元ネットワークアドレス** が表示される。

### 設置先リージョンとエニーキャスト
- **エニーキャスト**: 東京・石狩の各リージョンにLBが設置され、**両方とも常時アクティブで稼働**。接続元から **ネットワーク的に近いリージョン** のLBで処理 → リージョン間冗長性確保、レスポンスタイム短縮。
- **固定リージョン**: VIPはリージョン内ネットワークから払い出され、接続・実サーバ転送は該当リージョンで行われる。

### VIPフェイルオーバ機能（重要）
- LBへ疎通が取れなくなった場合に、接続点となる **VIPを自動的に別アドレスに変更** する機能。
- **デフォルトは無効。作成時にのみ有効に変更できる**。
- 有効にすると **VIPに加えてFQDNが払い出される** → クライアントは **FQDNに対してアクセス** する運用となる。
  - さくらインターネットのDNSでFQDNに対するIPアドレスがVIPとして定義される。
  - DDoS攻撃等でVIPへの疎通不可となると、紐づくVIPが自動的に別アドレスに変更される。

### ヘルスチェック（重要表）
- 監視プロトコルは **http または tcp** のいずれかを選択。
- 選択プロトコルで、実サーバ登録時に設定するポート番号に対しヘルスチェックを実施。

| 項目 | 仕様 |
|------|------|
| ヘルスチェックの実行間隔 | **10〜60秒**の範囲で変更可能 |
| ヘルスチェックのタイムアウト | **実行間隔と同値** |
| サーバダウン判定のリトライ回数 | **3回**（3回連続タイムアウトでダウン判定） |

## 3. 待ち受けプロトコル・ポートと実サーバ

### 待ち受けプロトコル
- プロキシ方式は **http / https / tcp** から選択。
- **https** を選択した場合、**SSL証明書の設定が必要**。
- **http** を選択した場合、**httpsへリダイレクトするか選択可能**。

> 💡 Tips: プロキシ方式に **https または http** を選択した場合、**LBと実サーバ間の通信はhttp** になる（実サーバとhttpsで通信することはできない）。プロキシ方式に **tcp** を選択した場合は、LBと実サーバ間の通信が **tcp** になる。

### 待ち受けポート
- **最大で2つまで** 設定可能。
- 仕様上、ポート番号に **22 と 179 を設定することはできない**。

### 実サーバの登録
- 設定項目: 実サーバのIPアドレス、ポート番号、サーバグループ。
- 設定可能なアドレス:
  - さくらインターネットが提供するサービスの **グローバルIPアドレス**（さくらのクラウド、さくらのVPS、さくらの専用サーバPHY など）。
  - **さくらのレンタルサーバ等の共用型サービスのアドレスは設定不可**。
  - **他社が提供するサービスのアドレスは設定不可**。
- 実サーバの **有効/無効** を設定でき、無効にした実サーバは振り分け対象にならない。

### サーバグループ
- 実サーバをグループ化できる。
- **所属できるグループは1つ**（複数グループへの所属不可）。
- サーバグループは **ルール機能で利用される**。

> 💡 Tips: サーバグループは **ルール機能とセットで利用**。ルールを設定しないと、サーバグループを設定した実サーバに通信が振り分けられない。

## 4. エンハンスドロードバランサの利用

### 起動・変更の制約（重要）
- **電源操作は無く、起動ステータスは存在しない**。有効状態が「利用可能」であれば利用できる。
- **作成後に変更できない項目**:
  - 配置先リージョン、固定とエニーキャストの変更
  - VIPフェイルオーバ機能の有効・無効の変更

### その他の設定
- **ソーリーサーバ** の設定が可能。
- **Syslog転送** が可能（アクセスログ・ヘルスチェックのログをSyslog経由で取得）。**Syslogサーバは利用者で用意**する必要がある。

### 代表的なL7関連機能

#### SSLオフロード機能
- LBにSSL証明書を設定可能 → **HTTPS処理の負荷を実サーバからLBへオフロード**。
- **Let's Encryptが発行する無料のSSL証明書** をインストール可能。**更新の自動化** も可能。

#### セッション維持機能
- 接続ごとに一意な文字列のCookieをセットし、通信する **実サーバを固定化**。
- **デフォルトは無効**。
- 有効にすると、クッキー名 **`sac-elb-session`** でランダムな文字列のセッションIDが付与される。
- 初回接続時に実サーバへ振り分けCookieセット → 2回目以降は同じCookieを持つ通信を同じ実サーバへ振り分け。

#### ルール機能（重要）
- リクエストヘッダの条件をもとに、実サーバへの転送など特定アクションを実行。
- 複数の条件・アクションを選択可能。条件合致時にサーバグループへ転送可能。
- **複数条件はAND条件**。
- **登録番号順に評価され、最初にマッチしたルールが適用される**。
- いずれのルールにもマッチしないリクエストは、**サーバグループが指定されていない実サーバ** に振り分けられる。

**設定可能な条件**

| 項目 | 条件 |
|------|------|
| ホストヘッダ | クライアントがリクエスト時に送出するHost:ヘッダ |
| パス | クライアントがGET/POSTでリクエストするパス |
| 送信元IP | リクエストの送信元IPアドレスまたはネットワーク |
| リクエストヘッダ名 | クライアントが送出する任意のヘッダ名 |
| リクエストヘッダ値 | リクエストヘッダ名で指定される値 |

**設定可能なアクション**

| 項目 | アクション |
|------|-----------|
| 実サーバへ転送 | 条件合致時に指定したサーバグループへ転送 |
| リダイレクト | 指定URLにリダイレクトし特定のステータスコードをレスポンス |
| 固定レスポンス | 指定したコンテンツタイプ・ボディ・ステータスコードをレスポンス |

#### オリジンガード機能
- 実サーバが **LBからの接続のみを許可** する機能。
- LBからのリクエストに含まれる **オリジンガードトークン** が実サーバの値と一致する場合のみ許可。
- トークン設定時、実サーバへのリクエストに **`X-Origin-Guard`** ヘッダを追加して送信。
- トークンは作成時または「設定変更」から追加。実サーバ側のWebサーバソフトウェア（Apache, Nginxなど）で同じトークン値を設定する。
- LB以外からの接続を抑制してセキュリティを強化。

## 5. VPNルータ

### 概要
- **クラウド上の仮想プライベートネットワーク**（仮想ルータ）。
- **VPN接続・ファイアウォール・ゲートウェイセキュリティ強化**、クラウド内部のプライベートネットワーク構築に用いる。
- ファイアウォール機能でクラウド内外の通信をフィルタリングし安全なネットワークを構成。
- 利用者の拠点側ネットワークとVPN接続し、クラウド上のリソースを **あたかも拠点側ネットワークの一部** として使用可能。

### 提供プラン（重要表）
- 性能と利用形態に応じた **4つのプラン**。

| プラン | 冗長化 | 上流ネットワーク | スループット | サイト間VPN |
|--------|:---:|------|------|------|
| スタンダード | ✕ | 共有セグメント | 80Mbps | 4拠点 |
| プレミアム | 〇 | ルータ＋スイッチ | 800Mbps | 20拠点 |
| ハイスペック(1,600Mbps) | 〇 | ルータ＋スイッチ | 1,600Mbps | 50拠点 |
| ハイスペック(4,000Mbps) | 〇 | ルータ＋スイッチ | 4,000Mbps | 50拠点 |

- 料金はプランに応じた **時間額・日額・月額**。

### ネットワーク構成（プランによる差異・重要）

| | スタンダードプラン | プレミアム・ハイスペックプラン |
|---|---|---|
| グローバル側IF 接続先 | 共有セグメント | ルータ＋スイッチ |
| グローバル側IF IPアドレス | 1つ（自動割り当て） | **VIP1つ + 物理IP2つ** |
| プライベート側IF 接続先 | スイッチ | スイッチ |
| プライベート側IF IPアドレス | 1つ | **VIP1つ + 物理IP2つ** |

### 機能一覧
- 代表的な機能: **リモートアクセスVPN / サイト間VPN / NAT / ファイアウォール**。
- その他: **DHCP機能 / DNSフォワーディングサーバ機能 / スタティックルート機能**。

### ログ
- VPNルータのログには **VPNのログ** と **ファイアウォールのログ** の2つ。
- ログは **Syslogサーバへ転送可能**（Syslogサーバは利用者で用意）。
- VPNのログはコントロールパネル「ログ」タブで確認・ファイルダウンロード可能。
- ファイアウォールのログは、ログ記録を有効にしたルールにマッチした通信が対象（受信方向・送信方向それぞれ確認可能）。
- 「ログ」タブでは **セッション統計情報** も確認可能。

### 電源操作・作成（重要）
- 停止・再起動などの操作が可能。**サーバと同様の操作が可能（cloud-init起動を除く）**。
- ⚠️ **VPNルータは作成後に自動起動しない**。スイッチに接続後、**利用者が手動で起動** する必要がある。
- 削除する場合は **停止** する必要がある。

### ネットワーク（作成時）
- **インターネット接続の有無** を選択可能（**デフォルトは接続有り**）。
- **IPv6 非対応**。
- プレミアム・ハイスペック選択時は、接続先のルータ＋スイッチを選択する項目が追加される。

### IPエイリアス
- グローバルネットワーク側インターフェースに **複数のIPアドレスを設定可能**。
- **プレミアム・ハイスペックプランで利用可**。

## 6. NAT機能

利用可能な機能: **IPマスカレード(Forward NAT) / ポートフォワーディング(Reverse NAT) / スタティックNAT(1対1 NAT)**。

### IPマスカレード（Forward NAT）※全プラン共通
- 標準で利用可能。
- ローカルIPが付与されたプライベートネットワーク内サーバから、**インターネット向け通信を実現**。
- **デフォルトで動作**。コントロールパネルでの設定項目は特になく、**機能を停止できない**。
- 動作: 送信元(Src)アドレス・ポートのペアをグローバルIP+任意ポートに変換し、戻りパケットの宛先(Dst)を逆変換。

### ポートフォワーディング（Reverse NAT）※全プラン共通
- 標準で利用可能。
- グローバル側IFの **特定ポートに着信する通信を、プライベートネットワーク内サーバへ転送**。
- 設定: プライベート側のIPアドレス・ポート番号 と グローバル側の着信ポート情報。

### スタティックNAT（1対1 NAT）※プレミアム・ハイスペックプランで利用可
- **IPエイリアスとして設定したグローバルIPアドレス** に着信した通信を、指定したローカルIPのサーバへ転送。

## 7. リモートアクセスVPN機能

### 概要
- **端末がインターネット経由でVPNルータと直接VPN接続**。

### ネットワーク仕様（重要）
- 利用可能なVPNプロトコルは **PPTP** または **L2TP/IPsec**。
- **PPP認証方法**: ユーザ名とパスワード。
- **IPsec認証方法**: 事前共有鍵(Pre-Shared Key)。
- **鍵交換モード**: **アグレッシブモード**（認証にIPアドレス情報を含まない → 動的IPでも可）。

> 💡 Tips: PPTPの方が通信速度は速いが、L2TP/IPsecの方がセキュリティレベルが高い。VPNルータの **WireGuardサーバ機能** を使うとWireGuardによるVPN接続も可能（高速・高セキュリティ）。L2TPは **標準的なL2TPv2 のみ利用可能**、**L2TPv3 は利用不可**。

### 設定の流れ
- 端末からVPNルータのグローバルIPアドレスに対してVPN接続。
- 端末に割り当てるIPアドレス範囲を設定（**クラウド内部のプライベートネットワークのプリフィックス範囲内** から割り当て）。
- リモートアクセス用アカウント（ユーザ名・パスワード）を設定。
- **L2TP/IPsecの場合は事前共有鍵(Pre-Shared Key)も設定**。

## 8. サイト間VPN機能

### 概要
- **拠点ルータがインターネット経由でVPNルータとVPN接続**。

### 提供プラン（仕様・重要）
- 利用可能なVPNプロトコルは **IPsec**。
- **認証方法**: 事前共有鍵(Pre-Shared Key)。
- **鍵交換モード**: **メインモード**（認証にIPアドレス情報を含むため、お互いに **固定IPアドレス** が必要）。

> 💡 Tips: 動的なグローバルIPアドレスでサイト間VPNを構成したい場合は、マーケットプレイスのセキュリティアプライアンスの利用を検討する。

### ネットワーク設定
- お互いのルータのグローバルIPアドレスに対してVPN接続。
- お互いで **対向IDと対向ネットワークのプリフィックス** を指定。
- ⚠️ **お互いのローカルネットワークのプリフィックスは異なる必要がある**。
- 事前共有鍵(Pre-Shared Key)を設定。

### IPsecパラメータ（利用者で変更可能・重要表）

| 項目 | デフォルト値 | 設定可能な値 |
|------|------|------|
| ISAKMP SAの寿命 | 28,800秒 | 30〜86,400秒 |
| IKEキープアライブ(DPD)インターバル | 15秒 | 10〜86,400秒 |
| IKEキープアライブ(DPD)タイムアウト | 30秒 | 30〜86,400秒 |
| IPSEC SAの寿命 | 1,800秒 | 30〜86,400秒 |
| 暗号アルゴリズム | AES128 | AES128 または AES256 |
| ハッシュアルゴリズム | SHA1 | SHA1 または SHA256 |
| DH(Diffie-Hellman)グループ | modp1024 | modp1024(グループ2)、modp2048(グループ14)、modp3072(グループ15)、modp4096(グループ16) |

### 利用時の機能
- **ステータス**: VPNの接続状況を確認可能。**UP** はVPN接続が確立しセッションが正常な状態。
- **特殊タグ**: サイト間VPNに関する特殊タグを設定可能。**VPNルータの特殊タグはサーバに適用しても効果なし**。
  - `@sitetosite-use-vti`: **VTI(Virtual Tunnel Interface)を使用する**。

### 閉域接続機能
- サイト間VPN以外のトラフィックについて、**VPNルータから直接インターネットへ送受信できなくなる**。
- クラウド上のリソースとインターネット間のトラフィックを、**拠点ルータの機能で通信制御・監査** 可能。
- 利用するには **対向Prefixを `0.0.0.0/0` に設定** する。

> 💡 Tips: 閉域接続機能を利用すると、VPNルータの **NAT機能・ファイアウォール機能・リモートアクセスVPN機能が使用不可** になる。サイト間VPNのセッションが切断された場合、再接続処理はされず **完全に通信断** となる。

## 9. ファイアウォール機能

### 概要
- VPNルータの **グローバルネットワーク側** / **クラウド内部のプライベートネットワーク側** それぞれのインターフェースに対し、**受信・送信** するパケットを指定条件でフィルタリング。

### フィルタリング条件（重要表）

| プロトコル | 指定可能な項目 |
|------|------|
| TCP | 送信元ネットワーク、送信元ポート、宛先ネットワーク、宛先ポート |
| UDP | 送信元ネットワーク、送信元ポート、宛先ネットワーク、宛先ポート |
| ICMP | 送信元ネットワーク、宛先ネットワーク |
| IP | 送信元ネットワーク、宛先ネットワーク |

### ルールの設定・評価（重要）
- 各インターフェースの受信方向 / 送信方向にルールを設定。
- 条件の空欄は **Any（全てが対象）** として設定される。
- ルールにマッチした通信をログ出力するには、アクションで「有効」を選択。
- 三本線アイコンをドラッグして上下移動するとルールの順番を変更可能。
- **設定されたルールは登録番号順に評価** され、条件にマッチしたパケットにアクションの動作が行われる。
- ⚠️ **いずれの条件にもマッチしなかったパケットは「許可」となり、ファイアウォールを通過する**。
  - 全て拒否したい場合は、**各条件を空欄にし、アクションで「拒否」を選択したルールをリスト末尾に追加** する。
- ⚠️ **ステートフル動作**: ルールリスト末尾に全て拒否を設定しても、**サーバ発の通信の戻りパケットは自動的に許可される**。

## 10. ブリッジ接続（ゾーン間接続サービス）

### 概要
- **異なるゾーンのスイッチ間をL2接続** するサービス。
- さくらインターネットの **周辺サービスと接続**（さくらの専用サーバPHY、さくらのVPS など）。
- 複数のロケーションを利用する **DR対策** に活用。

### プラン・料金
- **ブリッジ接続にプランは存在しない**。
- 料金は **時間額・日額・月額** が設定されている。

### 制約（重要）
- ⚠️ **ブリッジは単体では動作しない** → 別途スイッチを作成して接続する必要がある。
- **1つのブリッジには1ゾーンにつき1つのスイッチを接続**（同一ゾーンの複数スイッチは接続不可）。
- **同一プロジェクト内のスイッチにのみ接続可能**。
- 専用サーバPHYやVPSのスイッチと接続する場合は **会員IDでログイン** が必要。
- 削除する際は **すべてのスイッチを切断** する（接続されているスイッチがあると削除不可）。

> 💡 Tips: **1つのスイッチに複数のブリッジは接続不可**。接続対象として **ブリッジ接続・ハイブリッド接続・ローカルルータ** がある場合、これらのうち **いずれか1つのみ** 接続可能。**外部回線接続サービスが接続されているスイッチ** はブリッジに接続できず、**ハイブリッド接続** を利用する必要がある。クラウドと接続せず **さくらのVPSと専用サーバPHY間をブリッジで接続** することも可能（この場合もクラウドのコントロールパネルで操作）。**ルータ＋スイッチにブリッジを接続することはできない**。

## 11. 試験対策・要点チェック

- [ ] エンハンスドロードバランサ = **L7・プロキシ型・グローバルリソース**、振り分けは **least connection**、**IPv6非対応**。
- [ ] プラン名は **CPS** の上限を表す（最小**100cps**〜最大**400,000cps**）。**HTTPSはCPSがプラン名の1/10**。
- [ ] 実サーバは **1台あたり最大40台**。設置先は **固定(東京/石狩)** または **自動(エニーキャスト・両リージョン常時アクティブ)**。
- [ ] **VIPフェイルオーバはデフォルト無効・作成時のみ有効化可**、有効化で **FQDN** が払い出される。
- [ ] ヘルスチェック: 実行間隔 **10〜60秒**、タイムアウトは実行間隔と同値、**3回連続タイムアウトでダウン判定**。
- [ ] 待ち受けポートは **最大2つ**、**22 と 179 は設定不可**。https/http選択時は **LB〜実サーバ間はhttp**。
- [ ] 実サーバに **共用型サービス・他社サービスのアドレスは設定不可**。サーバグループは **ルール機能とセット**、所属は **1グループのみ**。
- [ ] 作成後に **リージョン/固定・エニーキャスト/VIPフェイルオーバの変更は不可**。電源操作・起動ステータスは無い。
- [ ] L7機能: **SSLオフロード(Let's Encrypt対応)** / **セッション維持(クッキー名 `sac-elb-session`)** / **ルール機能(登録番号順・AND)** / **オリジンガード(`X-Origin-Guard`)**。
- [ ] VPNルータ4プラン: スタンダードは **冗長化✕/共有セグメント/80Mbps/4拠点**。冗長化ありは **ルータ＋スイッチ接続(VIP1+物理IP2)**。
- [ ] VPNルータは **IPv6非対応**、**作成後に自動起動しない（手動起動）**、削除時は停止が必要。**IPエイリアスはプレミアム・ハイスペックのみ**。
- [ ] NAT: **IPマスカレード/ポートフォワーディングは全プラン共通・標準**（IPマスカレードは停止不可）、**スタティックNATはプレミアム・ハイスペックのみ**。
- [ ] リモートアクセスVPN: **PPTP / L2TP/IPsec**、鍵交換は **アグレッシブモード**、**L2TPv2のみ（v3不可）**。
- [ ] サイト間VPN: **IPsec・事前共有鍵・メインモード（固定IP必須）**。お互いのローカルプリフィックスは **異なる必要**。
- [ ] サイト間VPNのIPsec既定値: ISAKMP SA **28,800秒**、IPSEC SA **1,800秒**、暗号 **AES128**、ハッシュ **SHA1**、DH **modp1024**。
- [ ] 閉域接続は **対向Prefixを `0.0.0.0/0`** に設定。NAT・FW・リモートアクセスVPNが使用不可になる。特殊タグ **`@sitetosite-use-vti`**。
- [ ] ファイアウォールは **登録番号順・ステートフル**。**マッチしないパケットは許可**（全拒否は末尾に拒否ルールを追加）。戻りパケットは自動許可。
- [ ] ブリッジ接続は **プランなし・L2接続・単体では動作しない**。1ブリッジ=1ゾーン1スイッチ、同一プロジェクト内のみ。**ルータ＋スイッチには接続不可**。
