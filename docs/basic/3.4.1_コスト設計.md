## 1. 料金体系

### 2つの料金計算方法
さくらのクラウドサービスには、**2つの料金計算方法**がある。

| 料金計算方法 | 内容 |
|--------------|------|
| **従量課金** | リソースの利用時間に伴って課金。大部分のクラウドリソースが該当 |
| **月額料金制** | 時間割料金・日割料金の設定がなく、月額固定で課金 |

### 従量課金
- リソースの**利用時間に伴う従量課金**。大部分のクラウドリソースがこれに該当する。
- 一部のサービスを除き、**データ転送量に課金は発生しない**。
  - **オブジェクトストレージ等ではデータ転送量に課金が発生する**。
- **時間割料金・日割料金・月額料金**が設定されている。
  - ただし、時間割料金や日割料金の設定がないリソースも存在する。
    - **シンプル監視・DNSアプライアンス**: 時間割料金の設定なし
    - **ルータ＋スイッチのルータ部**: 日割料金の設定なし

#### 課金条件（最重要・逐語）
- **最小1時間単位からの課金**となる。**1時間未満の端数は1時間分として切り上げ**される。
- 料金は以下の関係で設定されており、利用時間に合わせて**一番安い料金が適用**される。
  - **10時間分の時間割料金 = 1日分の日割料金**
  - **20日分の日割料金 = 1か月分の月額料金**

> 【Tips】料金の計算方法（逐語）
> 契約ごとに契約開始から解約までの利用時間を**秒単位**で算出し、**時間割料金と日割料金を加算した金額**と、**月額料金として設定されている金額**が比較されて、**少ない方の金額**が各契約の請求金額となります。

> 【Tips】月額料金について
> 一部のサービスを除きデータ転送量に課金が発生せず、**20日以上使うと月額料金が適用**されることから、発生するコストを事前に見積もりやすく予算が立てやすいという特徴がある。

### サーバとディスクの料金（課金開始の違い）
両方とも従量課金だが、利用時間の数え方が異なる。

| リソース | 課金対象（利用時間の数え方） |
|----------|------------------------------|
| **サーバ** | **1ヶ月間の起動時間の総和**が利用時間（＝停止中は課金されない） |
| **ディスク** | **作成された時点から削除されるまでの期間**が課金対象（起動・停止に関わらず） |

### データベースアプライアンスの料金
従量課金だが、**冗長化オプションの有無**で課金対象が異なる。

| 区分 | 課金対象 |
|------|----------|
| **冗長化オプションなし / リードレプリカ** | **1ヶ月間の起動時間の総和**（**データベース停止時非課金制度**の対象） |
| **冗長化オプションあり** | **作成時点から削除されるまでの期間**（停止中も課金） |

> 【Tips】データベース停止時非課金制度の対象・対象外
> - **対象**: **2024年9月26日以降に作成**された、冗長化オプションなしのデータベースアプライアンス、またはリードレプリカ。
> - **対象外**:
>   - 冗長化オプションのデータベースアプライアンスの契約
>   - 2024年9月25日以前に作成された冗長化オプションなしのデータベースアプライアンス
>   - 2024年9月25日以前に作成されたリードレプリカ機能によって作られたリードレプリカ部分

### 月額料金制
- **時間割料金・日割料金の設定がない**料金制。
  - **ライセンス**や**ルータ＋スイッチのプリフィックス**等が該当する。
- 一部のサービスでは月額料金に加えて**初期費用**が発生する（**ハイブリッド接続等、サービス間接続の一部**が該当）。
- 月額料金制のリソースは、**作成する度に月額料金が発生**する。
  - そのため、**同一月内に作成・削除を繰り返すと相当数の料金が発生**する（注意点）。

> 【Tips】従量課金と月額料金制（間違えやすいもの・試験頻出）
>
> | リソース | 区分 |
> |----------|------|
> | Windows Server Datacenter Edition ライセンス | **従量課金** |
> | Windows Server for リモートデスクトップ / 同(MS Office付き) ライセンス | **月額料金制** |
> | ルータ＋スイッチ | **従量課金** |
> | ルータ＋スイッチのプリフィックス（追加IPアドレス） | **月額料金制** |

### 障害発生時の料金計算
- 利用中のサーバが稼働する**ホストサーバに障害**が発生した場合、**障害発生時から復旧までの期間**は、対象のサーバは**停止状態として扱われ、請求対象の利用時間には含まれない**。
- すなわち「サーバが起動している期間のみ請求対象」。

### プラン変更時の料金計算
- サーバのプランを変更した場合、変更した時点で**変更前のプランは利用終了**となり、**変更後のプランによる課金が新たに開始**される。各サーバプランの利用時間に応じて課金が**積算**される。
- **以前と同じプランに戻した場合でも**、変更前と変更後のプランは**別々の課金対象**となり、それぞれの利用時間に応じた課金が積算される。

### 料金シミュレーション
- 指定したリソース数やプランに基づき、利用料金を**事前に試算**できる。
- さくらのクラウドの**サービスサイトで提供**され、**誰でも無料**で使用できる。
- オンライン上で**PDF形式の見積書**を発行することも可能。

## 2. 支払方法

### 支払い方法の種類
- 基本は**クレジットカードによる後払い**。
- **請求書払い・銀行振込**へ変更したい場合は、さくらインターネットへ依頼可能（**サポート窓口または営業担当者**に連絡）。
- 次の場合は**銀行振込での請求**が行われる。
  - クレジットカードでの支払いに問題が発生した場合
  - **1回の請求額が1,000万円以上**となった場合
- **法人の場合**は、**プリペイド購入による前払い**も選択できる。

### プリペイド
- **法人の利用者向け**に提供される**前払い**の支払い方法。
- **2種類**が提供されている。

| 種類 | 利用可能期間 |
|------|--------------|
| **通常のプリペイド** | プリペイドIDの登録から**1～36ヶ月間** |
| **単年度プリペイド** | 登録から**その年度の3月末まで** |

- 事前の見積りによる予算確保が必要な場合などに使う。
- **個人の利用者はプリペイドを申込めない**。

#### 単年度プリペイド
- **国公立大学や公的機関など、単年度会計組織の法人向け**を想定。
- 有効期間を**年度末に設定**することで、単年度で**残高を0円**にできる。

### 請求書とインボイス対応
- 支払い方法に関わらず、**会員メニュー**と**クラウドコントロールパネルの請求情報メニュー**から、請求書の**印刷・PDF/CSV形式でのダウンロード**ができる。
- **クラウドコントロールパネルの請求情報は、プロジェクト単位でリソースごとの料金**が表示される。
- **適格請求書（インボイス）要件**に準拠した請求書としての発行・取り扱いには、以下の**2つの請求書を組み合わせる**。
  - 会員メニューより印刷・ダウンロード可能な請求書
  - コントロールパネルから印刷・ダウンロード可能な請求書

## 3. リソースの使用状況とコストの把握（コストの可視化）

### 検討にあたっての考慮事項
- 契約状況と発生コストを把握し利用料金を最適化する手段として、**契約リソース機能・最適化サジェスト機能・利用料金管理・料金アラート機能**の利用を検討する。
- 提供サービスや開発プロジェクトごとに**プロジェクトを分ける**ことで請求情報を分割し、コストを**プロジェクト単位で管理**できる。
- 請求情報の分割は、コストを可視化し全体のコスト管理を効率化する一つの手段。

### コスト把握機能の比較（重要）

| 機能 | 概要 | ポイント |
|------|------|----------|
| **契約リソース機能** | 選択中プロジェクトの料金請求・利用料金推移・リソース利用状況を一覧表示 | 集計は課金システム連携で**リアルタイムではない**。**1日ごと、深夜帯**に集計 |
| **最適化サジェスト機能** | リソース利用状況に応じ最適な利用方法を提案 | 長期利用中サーバへの**割引パスポート提案**などの改善提案 |
| **利用料金管理** | 利用料金の可視化・分析に必要な情報を提供 | 過去比較・平均利用料金確認・**CSV出力**可。表示期間は**最大36か月**（初期は直近6か月） |
| **料金アラート機能** | 請求額や残額が閾値を超過/下回った際に通知 | **無料**。通知先は**メール・Slack・Discord** |

### 契約リソース機能
- 選択中のプロジェクトに関する**料金請求・利用料金の推移・リソース利用状況**を一覧で確認できる。
- 過去との料金比較や、**ゾーンごとのリソース数を比較**する場合などに使う。
- 表示される情報（利用料金およびリソース数）は**リアルタイム表示ではない**。課金システムと連携して表示するため、**集計が行われた時点の情報**が表示される。
- 集計は**1日ごと、深夜帯**に実行される。
- コントロールパネルの**ホーム画面の「契約リソース」**から、プロジェクトを選択して確認する。

### 最適化サジェスト機能
- リソースの利用状況に応じて、**最適な利用方法を提案**する機能。
- 長期間利用中のサーバに対する**割引パスポートの提案**など、クラウド運用に関する改善提案が表示される。

### 利用料金管理
- 利用料金の**可視化および分析**に必要な情報を提供する機能。
- グラフにマウスカーソルを重ねると**カテゴリごとの金額**が表示される。
- **過去の料金との比較・平均利用料金の確認・CSV出力**ができる。
- 表示期間は**最大36か月間**まで変更可能。**初期状態では直近6か月間**が選択。
  - カレンダーから開始月・終了月を選択、または「直近3か月」「直近6か月」「直近1年間」から選択。
  - 期間の指定は**「月」単位**で、**「日」部分は無視される**。

### 料金アラート機能
- 次回請求額が一定額を超過、またはクーポン/プリペイド残額が一定額を下回った場合に、**メール・Slack・Discord**へアラートを発報する機能。
- **無料**で使える。
- **3種類**のアラートがある。

| アラート種別 | 通知条件 | 設定場所 |
|--------------|----------|----------|
| **次回請求額アラート** | 次回請求額が指定金額を**上回った**場合 | ホーム画面の**「利用料金管理」** |
| **予測利用料金アラート** | 月末までの**予測利用料金**が指定金額を**上回った**場合 | ホーム画面の**「利用料金管理」** |
| **クーポン・プリペイド残額アラート** | クーポンやプリペイドの残高が指定額を**下回った**場合 | オプションの**「クーポン」** |

## 4. 割引制度の活用

### 検討にあたっての考慮事項
- 提供されている**割引パスポート**を理解し、選択予定のリソース・利用期間・プランが**割引制度の適用対象か**を確認する。
- 割引パスポート利用で発生する**制限も考慮**して適用を検討する。

### 割引パスポート
- **利用権を購入**することで、利用中のクラウドリソースの料金を割引する制度。
- 割引パスポート利用権は**購入した時期によらず、すでに作成済みのサーバに対しても割引適用範囲内**となる。
- 購入したパスポートの有効期間に応じ、**12ヶ月・24ヶ月・36ヶ月分**の請求に対して割引が適用される。
- **長期利用を前提**としている場合に有効活用できる。
- **割引率や料金例はクラウドマニュアルで確認**できる。

#### 割引対象・対象外（重要）

| 区分 | リソース |
|------|----------|
| **割引対象** | サーバ（**通常プラン・専有ホスト**）、**VPNルータ**、**ロードバランサ**、**オブジェクトストレージのアーカイブプラン** |
| **割引対象外** | サーバの**コア専有プラン**、**ディスク**、**Windowsライセンス** 等 |

- 割引パスポート購入時に**ゾーンとリソースのプランを選択**する。
- 割引対象は**特定のクラウドリソースには紐付かない**。利用券を購入したプロジェクトの請求の中で、**請求額の上位から契約個数分が自動的に割引対象**となり、**自動的に最大の割引が適用**される。
- 購入はコントロールパネルの**オプションの「割引パスポート」**から行う。

### クラウドクーポン（その他の割引制度）
> 【Tips】クラウドクーポン
> - さくらインターネットが主催・協賛する勉強会・セミナー、キャンペーン等で配布される場合がある。
> - クーポン券に印字された**クーポンコード（16桁の数字）**をコントロールパネル上で登録、またはキャンペーン参加で、記載金額分を**無料で利用**できる。
> - クーポン利用には、**会員IDとプロジェクトが登録**されている必要がある。

## 5. 試験対策・要点チェック

- [ ] 料金計算方法は**従量課金**と**月額料金制**の2つ。
- [ ] 従量課金は**最小1時間単位**、**1時間未満は1時間に切り上げ**。
- [ ] **10時間分の時間割=1日分の日割**、**20日分の日割=1か月分の月額**。利用時間に応じ**一番安い料金**が適用。
- [ ] 計算方法: 秒単位で利用時間を算出し、**時間割+日割の合計** vs **月額**を比較して**少ない方**が請求額。**20日以上**で月額適用。
- [ ] **サーバ＝起動時間の総和**、**ディスク＝作成～削除の期間**で課金。
- [ ] DB停止時非課金制度: **冗長化なし/リードレプリカ**かつ**2024/9/26以降作成**が対象。冗長化ありは作成～削除で課金。
- [ ] データ転送量課金は原則なし。ただし**オブジェクトストレージ等**は転送量課金あり。
- [ ] 月額料金制は**作成の度に月額発生**＝同一月内の作成・削除繰り返しに注意。
- [ ] 間違えやすい: **Datacenter Editionライセンス=従量**、**リモートデスクトップ系ライセンス=月額**、**ルータ＋スイッチ=従量**、**プリフィックス=月額**。
- [ ] **障害発生時**は復旧までサーバ停止扱いで請求対象外。**プラン変更**は変更前後で別課金・積算（同プランに戻しても別課金）。
- [ ] **料金シミュレーション**は無料・誰でも利用可、**PDF見積書**発行可。
- [ ] 支払いは原則**クレカ後払い**。**1回1,000万円以上**は銀行振込。**プリペイドは法人のみ**（個人不可）。
- [ ] プリペイドは**通常（1～36ヶ月）**と**単年度（その年度3月末まで）**。単年度は公的機関等向け、残高0円化が可能。
- [ ] インボイス対応は**会員メニューの請求書 + コントロールパネルの請求書**の組み合わせ。
- [ ] **契約リソース機能**は非リアルタイム、**1日ごと深夜帯**に集計。
- [ ] **最適化サジェスト**は割引パスポート提案等。**利用料金管理**は最大**36か月**表示・初期**6か月**・**CSV出力**可・期間は月単位。
- [ ] **料金アラートは無料**、通知先**メール/Slack/Discord**、3種（次回請求額・予測利用料金・クーポン/プリペイド残額）。クーポン/プリペイド残額のみ**「クーポン」**で設定。
- [ ] **割引パスポート**は購入時期を問わず既存サーバにも適用。**12/24/36ヶ月**。対象=**通常プラン/専有ホストサーバ・VPNルータ・ロードバランサ・OSアーカイブプラン**。対象外=**コア専有プラン・ディスク・Windowsライセンス**。
- [ ] 割引パスポートはリソースに紐付かず、**請求額上位から契約個数分**に**自動で最大割引**。
- [ ] **クラウドクーポン**は**16桁**コード、会員IDとプロジェクト登録が必要。
