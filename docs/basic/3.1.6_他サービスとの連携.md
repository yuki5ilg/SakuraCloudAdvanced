## 1. 他サービスとの連携

### 1-1. VPSとの連携

さくらのVPSとさくらのクラウドを**併用**する。

- **さくらのVPS**: 安価な料金
- **さくらのクラウド**: 高い可用性と拡張性

連携パターンは3種類。

| パターン | 接続方法 | 概要 |
|----------|----------|------|
| L2接続 | **ブリッジ**を使ってプライベートで**L2接続**する | クラウドとVPSをプライベートに接続 |
| VPN接続 | **VPNルータ**を用い**VPN経由**でVPSに接続する | VPNトンネルで安全に接続 |
| 負荷分散 | **エンハンスドロードバランサとVPSを組み合わせて利用する** | エンハンスドロードバランサで複数VPSへ振り分け |

> 図（p.8/p.9）: ブリッジによるL2接続、VPNルータ経由のVPN接続、エンハンスドロードバランサ配下に複数のVPSを並べる構成が示される。

### 1-2. 専用サーバ（PHY）との連携

さくらの専用サーバPHYとさくらのクラウドを**併用**する。

- **さくらの専用サーバPHY**: 高性能
- **さくらのクラウド**: 高い可用性と拡張性

| パターン | 接続方法 | 概要 |
|----------|----------|------|
| L2接続 | **ブリッジ**を使ってプライベートで**L2接続**する | クラウドと専用サーバPHYをプライベート接続 |
| VPN接続 | **VPNルータ**を用い**VPN経由**で専用サーバに接続する | VPNトンネルで安全に接続 |
| 物理サーバ活用 | **高性能な物理サーバの特性を活かす** | 例: Webサーバをクラウド側、データベースサーバを専用サーバPHY側に配置 |

> 図（p.12）: 「高性能な物理サーバの特性を活かす」構成では、さくらのクラウドに**Webサーバ**、さくらの専用サーバPHYに**データベースサーバ**を配置し、ブリッジで接続する例が示される。

### 1-3. ハウジングサービスとの連携

ハウジングサービスとさくらのクラウドを**併用**する。

- **ハウジングサービス**: 利用者の機器を持ち込み
- **さくらのクラウド**: 高い可用性と拡張性

| パターン | 接続方法 | 概要 |
|----------|----------|------|
| ハイブリッド接続 | **ハイブリッド接続**を使ってプライベートで接続する | クラウドとハウジング環境をプライベート接続 |
| 閉域網の引き込み | ハウジングラック内に**閉域網を引き込む** | 利用者拠点とハウジング・クラウドを閉域網で接続 |
| クラウドでのリソース追加 | ハウジング環境をメインで利用し、追加でリソースが必要になったらクラウドを利用する | 必要に応じてクラウド側のリソースを**作成/起動**してスケール |

> ⚠️ 試験頻出: 接続方式が連携先ごとに異なる。
> - VPS / 専用サーバ = **ブリッジ（L2接続）** または **VPN（VPNルータ）**
> - ハウジング = **ハイブリッド接続**（プライベート接続）/ **閉域網の引き込み**

## 2. マーケットプレイス

### 2-1. マーケットプレイスとは

- さくらインターネット**以外のメーカーまたはベンダーが開発したサービス**を、さくらのクラウドが**公式に提供、再販売**するもの。
- **サーバと異なる領域**の製品とサービスが提供されている。
- **さくらインターネットよりライセンスが提供される**。
- **提供元よりライセンス発行が許可されているサービスに限る**。

### 2-2. 料金

| 料金区分 | 内容 |
|----------|------|
| **定期払い** | 月ごとに支払いが必要なサービスに関する請求方法 |
| **1回払い** | 作業に対する料金請求、または履行義務の伴わないサービスに関する請求方法 |

### 2-3. 利用方法（提供形態）

提供形態は2種類。

| 利用方法 | 内容 |
|----------|------|
| **OS/アーカイブ提供** | 予めライセンスが設定されたOS/アーカイブを利用する（**ライセンス埋込済**） |
| **ライセンス申し込み型** | さくらインターネットから発行されるライセンスを、利用者がOS/管理コンソールなどに設定して利用する |

> 【Tips】ライセンスが埋め込まれていないOS/アーカイブが提供される形態もある（**非ライセンス埋込型**）。こちらの利用には別途ライセンスの申し込みが必要。

### 2-4. サポート

さくらインターネットによる**無償サポート**が付帯される。

- 提供される: 製品・サービスに関する**一般的な問い合わせと回答**、**バグ・不具合問い合わせ**。
- 提供されない: **利用者環境のシステムを俯瞰したサポート**、**製品・サービス操作の伴うサポート**。
- 各製品・サービスの機能詳細や設定例の一部は**クラウドマニュアル**に記載。詳細確認は**提供元のマニュアルや公開コミュニティサイト**を参照する。
- 提供元で発生する**メンテナンスや障害の情報**は、それぞれの製品やサービスのウェブサイトなどで通知される。**さくらインターネットのメンテナンス・障害情報としては掲載されない**。

## 3. マーケットプレイス利用の検討

マーケットプレイスで提供される製品やサービスは、以下の場合に利用を検討する。

- 各製品やサービスが提供する**独自の機能**を利用したい場合。
- さくらのクラウドの機能やリソースでは**システム要件を満たせない**、もしくは要件を満たせるが**不十分**な場合。

### 提供されるサービスカテゴリと主な特徴

| カテゴリ | 主な特徴・機能 |
|----------|----------------|
| **バックアップサービス** | 物理/仮想サーババックアップ・復元、頻繁にディスクI/Oが発生するサーバの自動バックアップ、時間指定のスケジュールバックアップ、ファイル単位での復元、Web管理画面によるバックアップの一元管理 |
| **サーバセキュリティサービス** | サーバ内検査・マルウェア隔離/削除、管理コンソールによる集中管理、ソフトウェアの意図しない動作を制限、侵入防御の実現、セキュリティ・エンドポイント管理 |
| **セキュリティアプライアンス** | VPN、IPS、ファイアウォール、WAF、ウェブフィルタリング、メールフィルタリング、アプリケーションコントロール |
| **WAFサービス** | 高度なWAF機能、エージェント型WAF、クラウド型WAF、国産サービス |
| **監視サービス** | リソースを一元監視、アラート機能、障害検知 |
| **分析サービス** | データソースとの連携、データの可視化、データ加工、ETLツール、BIツール |

## 4. 試験対策・要点チェック

- [ ] 他サービス併用の共通の狙い: クラウドの**高い可用性と拡張性**で補完する。
- [ ] VPSの強み = **安価な料金** / 専用サーバPHYの強み = **高性能** / ハウジング = **利用者の機器を持ち込み**。
- [ ] VPS・専用サーバとの接続方法 = **ブリッジ（L2接続）** または **VPN（VPNルータ）**。
- [ ] VPSは**エンハンスドロードバランサ**と組み合わせて負荷分散できる。
- [ ] 専用サーバPHYは「Webサーバ＝クラウド／DBサーバ＝PHY」のように**物理サーバの特性を活かす**構成が可能。
- [ ] ハウジングとの接続 = **ハイブリッド接続**（プライベート接続）/ **閉域網の引き込み**。ハウジングをメインに、不足分をクラウドで**作成/起動**して補える。
- [ ] マーケットプレイス = さくら**以外**のベンダー製品をさくらが**公式に再販売**。**ライセンスはさくらから提供**、提供元の許可があるものに限る。
- [ ] 料金は**定期払い**（月ごと）と**1回払い**（作業/履行義務なし）。
- [ ] 利用方法は **OS/アーカイブ提供（ライセンス埋込済）** と **ライセンス申し込み型**。非ライセンス埋込型は別途申し込みが必要。
- [ ] さくらの**無償サポート**は一般的問い合わせ・バグ報告まで。**操作を伴うサポートやシステム俯瞰サポートは対象外**。障害/メンテ情報は**提供元側で通知**（さくらの障害情報には掲載されない）。
- [ ] 利用検討の判断軸 = **独自機能を使いたい** / **クラウド単体では要件を満たせない・不十分**。
- [ ] 提供カテゴリ = バックアップ / サーバセキュリティ / セキュリティアプライアンス / WAF / 監視 / 分析。
