## A. 横断・最重要比較表

### リージョン / ゾーン 🔢
- **リージョン＝地理的単位**（石狩・東京、リソース配置不可）／**ゾーン＝物理独立のNW管理単位**（石狩第1/2/3・東京第1/2、リソース配置・操作の単位）。
- **同一ゾーン内のみ**: サーバ-ディスク接続、スイッチ接続、アーカイブからのディスク作成。**ゾーン跨ぎ可**: ブリッジ接続・ハイブリッド接続。
- **グローバルリソース** = GSLB / ローカルルータ / エンハンスドロードバランサ / シンプル監視。
- ⚠️ 同一リージョン内のゾーン分散は**DR目的では非推奨**（建屋の電源設備が単一障害点になりうる）。

### 提供サービス3区分
| | クラウドインフラ | VPS | クラウドアプリ(レンタルサーバ) |
|--|--|--|--|
| 提供形態 | 専用 | 専用 | 共用 |
| 料金 | 時間割/日割/月額（最安適用） | 月額のみ | 月額のみ |
| API | ○ | × | × |
| 管理者権限 | ○ | ○ | × |
| スケール | アップ/アウト可 | **アウト不可**・アップはCPで可 | 不可 |
- ⚠️ **VPSとクラウドの違い＝可用性**。VPSは物理障害で停止、クラウドは別物理で即時復帰。

### 負荷分散3種 ⚠️最頻出
| | ロードバランサ(アプライアンス) | GSLB | エンハンスドLB |
|--|--|--|--|
| レイヤ/方式 | **L4・DSR** | **DNSラウンドロビン相当** | **L7・プロキシ** |
| リソース種別 | ゾーン内（同一スイッチ配下） | グローバル | グローバル |
| IPv6 | 非対応 | **対応** | 非対応 |
| 実サーバ上限 | **40台** | **12台** | 40台/グループ |
| セッション維持 | なし(least conn) | － | **クッキー `sac-elb-session`** |
| 冗長 | VRRP(二重化) | 標準で冗長 | 標準で冗長・エニーキャスト |
| TTL/FQDN | － | **TTL10秒**・`site-XX.gslbXX.sakura.ne.jp` | VIPフェイルオーバで払い出し |
- ⚠️ GSLB/エンハンスドは**ローカルIPを実サーバ登録不可**（VPNルータNATで対応）。
- ⚠️ エンハンスドLBの**プラン名＝CPS上限**（100〜400,000cps）、**HTTPSはプラン名の1/10**。待受ポート最大2つ、**22と179は不可**。

### 接続方式の使い分け 🔢
- **L3で別会員ID/別プロジェクト** → ローカルルータ（帯域1Gbpsベストエフォート、ピア設定は両方に必要）
- **L2で別ゾーン** → ブリッジ接続（プランなし・単体では動作しない・ルータ＋スイッチ不可）
- **L2で別サービス(ハウジング等)** → ハイブリッド接続（申込制・さくらが接続作業、解約は書面）
- **ブリッジ＜ハイブリッド**（ハイブリッドの方が接続可能サービスが多い）。ブリッジ→ハイブリッドは**ダウンタイムなし**で変更可。

### スイッチ / ルータ＋スイッチ 🔢
- スイッチ＝**L2・ローカル・プランなし**。ルータ＋スイッチ＝**L3・インターネット接続・グローバルIPバンドル**。
- ルータ帯域 **100Mbps〜10Gbps**（**10Gbpsは東京第2ゾーンのみ**）。追加IP **16個(/28)〜256個(/24)**、**/25・/24は法人申込制**。
- ⚠️ **使用可能IP数 = 追加IP数 − 5**（NW1・ブロードキャスト1・GW3）。
- 帯域はメモリ依存: **32GB未満=1.0 / 〜128GB=2.0 / 〜224GB=5.0 / 224GB以上=10.0Gbps**。
- 共有セグメント＝**アウトバウンド100Mbps制限・インバウンド無制限・無料**。

## B. 大項目2 さくらインターネットのサービス
- さくらのクラウドは**2011年11月開始のIaaS**。独自特長＝**データ転送量の従量課金なし**・国内2リージョン使い分け・最安料金・API/Terraform対応。
- パブリッククラウドの**NIST 5特性**: オンデマンド・セルフサービス / 幅広いNWアクセス / リソースの共用 / スピーディな拡張性 / 計測可能。
- 高火力: **DOK=GPUコンテナ(Dockerイメージ実行) / VRT=VM型GPU / PHY=GPUベアメタル(H100/H200/B200)**。
- 物理基盤: ハウジング（石狩・堂島・東新宿・西新宿・代官山）/ 専用サーバPHY / 高火力PHY。
- 周辺サービス6種: ドメイン / SSL / **ImageFlux(画像変換・配信)** / IoT / **マーケットプレイス(ライセンス自動課金)** / プレミアムサポート。
- プレミアムサポート＝**24時間365日・有償(階段式)・フリーコール**、初回回答 仕様/操作8h・障害2h。標準サポートは無償・平日10-18時。

## C. 大項目3.1 システム構成設計

### 3.1.1 コンピューティング 🔢
- 通常プラン **1コア/1GB〜20コア/224GB**。コア専有 **2コア/4GB〜192コア/1024GB**（Intel Xeon / AMD EPYC 7003 / 9004）。
- 高火力VRT: **石狩第1ゾーンのみ**、**時間額は24時間まで**、**Windows Server不可**、GPUドライバは利用者導入。
- NIC **最大10個**、追加NICは**グローバル接続不可・スイッチ接続必須**、既定 **VirtIO**、逆引きは1つ目のみ。
- ディスク **1サーバ最大3台**、ISOは1サーバ1つ。
- 特殊タグ: **@cpu-topology(1ソケット化)** / **@group=A/B/Cでホスト分散** / @auto-reboot。
- スタートアップスクリプト: **SHELL=毎回 / YAML_CLOUD_CONFIG=初回のみ**、@sacloud-onceで1回。
- ⚠️ **Oracle Databaseはクラウド上で利用不可（持ち込み不可）** → PHY/ハウジングで連携。

### 3.1.2 ストレージ 🔢
- ディスク **標準40GB〜12TB / SSD 20GB〜16TB**（2TB超は東京第2・石狩第3のみ）。**サイズ変更不可**（付け替えで拡張）。IF＝VirtIO/IDE。
- パーティション拡張は**8/12/16TB非対応**、対応FS=**ext2/3/4**。
- 専有ストレージ: **最大32TB / 1ディスク16TB / IOPS50,000 / 1GB/s / 東京第2ゾーンのみ**、プランなし・申込＋審査。
- NFSアプライアンス: 標準100GB〜12TB / SSD 20GB〜4TB、**NFSv3/4・/export・グローバルIP不可・認証なし・IPv6非対応・シングル構成**。
- オブジェクトストレージ: **S3互換**、サイト=石狩第1/東京第1、基本料金範囲=容量100GiB/転送10GiB/リクエスト10万/オブジェクト10万。ACL既定=**private**、**CRR=石狩第1→東京第1 片方向・非同期**。
- ⚠️ オブジェクトストレージ通信は**グローバルNW経由（ローカル接続不可）**。**サービスポイントゲートウェイ**で内部完結。

### 3.1.3 ネットワーク（要点は §A も参照）
- パケットフィルタ: **無料・ステートレス**、上から評価、**マッチしなければ許可**、全拒否は末尾にdeny。**戻りパケット許可が必要**。
- VPNルータ4プラン: スタンダード=**冗長化×/共有セグメント/80Mbps/4拠点**。冗長化ありはルータ＋スイッチ接続。**IPv6非対応・手動起動**。
  - NAT: **IPマスカレード/ポートフォワーディングは全プラン**、**スタティックNATはプレミアム/ハイスペックのみ**。
  - リモートアクセスVPN: **PPTP / L2TP/IPsec**。サイト間VPN: **IPsec・事前共有鍵・メインモード・固定IP必須**、ローカルプリフィックスは相互に異なる必要、**BGP/動的ルーティング不可**。
  - サイト間VPN既定: ISAKMP SA28,800秒 / IPSEC SA1,800秒 / AES128 / SHA1 / modp1024。
- DNSアプライアンス: **権威・プライマリ専用**（キャッシュ/セカンダリ/ゾーン転送不可）、**ALIAS対応(CNAME不可)**、IDNはPunycode、料金は日額/月額。
- シンプル監視: **IPv4グローバルIPのみ**、間隔1〜60分(標準1分)、**ping/tcp/http/smtp**、リソース監視不可。
- 閉域接続: AWS=**Equinix TY2/Direct Connect**、**LGWANコネクト・外部回線接続は石狩リージョンのみ**、OCXはBBIX提供。**AWS接続オプション・LGWANはローカルルータ必須**。

### 3.1.4 データベース 🔢
- **リレーショナル型**、RDBMS=**PostgreSQL/MariaDB**（**Oracle不可**）。ディスクは**全プランSSD・料金込み**。
- 冗長化オプション=2台・常時同期・同一ゾーン・**必要IP3個**・レプリケーション不可。
- リードレプリカ=**最大3台・非同期(数秒〜数十秒遅延)・昇格なし・バックアップ取得不可**。
- ⚠️ **冗長化オプションとリードレプリカは併用不可**。
- データベースクラスタ=**3ノード(ゾーンA/B/C)・Active-Activeマルチマスター**。
- デフォルトポート **5432/3306**、**共有セグメント不可**、作成後NW変更不可。
- バックアップ最大8世代。**バックアップ(v1)** か **継続的バックアップ(PITR・NFS必須・別アプライアンスで復元、冗長化構成では不可)** のいずれか一方。
- バージョン更新: **パッチ=更新機能 / メジャー・マイナー=クローン**。

### 3.1.5 データ処理 🔢
- アーカイブ: **プランなし・20GB〜1TB・サーバ接続不可・ディスクより安価・FTP可**。Windows Serverのアーカイブは**FTP接続不可**。削除後**復旧不可**。
- 自動バックアップ: **週単位・曜日指定（日付/時間不可）、指定曜日24h中ランダム**、**最小1日/最大10世代/ソース最大1TB**、タグ `autobackup-{リソースID}`。DB等の頻繁I/Oは**非推奨**。
- ディスクマイグレーション: rawイメージをFTPアップロード（動作保証なし）。**ライブマイグレーション**はさくらが自動実行・無影響・属性引継ぎ。
- アーカイブは**ファイル単体復元不可**。他ゾーンコピーは**アーカイブ経由の3ステップ**。

### 3.1.6 他サービス連携
- VPS=安価 / 専用サーバPHY=高性能 / ハウジング=機器持ち込み。
- 接続: VPS/専用サーバ=**ブリッジ(L2) or VPN**、ハウジング=**ハイブリッド接続/閉域網引き込み**。
- マーケットプレイス=さくら以外の製品を**公式再販売・ライセンスはさくらから提供**。料金=定期払い/1回払い。**無償サポートは一般問い合わせ・バグ報告まで**（操作サポート対象外）。

## D. 大項目3.2 セキュリティ設計

### 3.2.1 リソースのセキュリティ
- 会員ID=**英字3＋数字5**、管理者権限・全プロジェクトアクセス可。プリンシパル3種=**ユーザ/グループ/サービスプリンシパル**。
- リソース階層=**組織＞フォルダ＞プロジェクト**、リソースID=**12桁**。
- ⚠️ **IAMポリシー＝リソースへのアクセス制御 / IDポリシー＝ユーザ・グループへの制御**。権限の束＝ロール。
- 操作4段階: **リソース閲覧 ＜ 電源操作 ＜ 設定編集 ＜ 作成・削除**（上位が下位を包含）。
- **会員IDログインは2要素認証必須**（FIDO2 or TOTP）。**SSO=SAML2.0**、**ユーザープロビジョニング=外部IdP同期（パスワード持たずSSO認証）**。
- イベントログ=操作・ログイン履歴＋ソースIP＋日時、**過去1年・CSV最大1000件**。リモートアクセスは**SSH/RDP＋公開鍵認証**。

### 3.2.2 データのセキュリティ
- 認証の主体別: **会社=Pマーク/ISMS** / **クラウド=ISMSクラウドセキュリティ/ISMAP** / **石狩DC=SOC2 Type2・SOC3・PCI DSS**。
- **ISMAP**=政府情報システム向け評価制度。**PCI DSS Ver.4.0**（要件9・12）。
- SSL証明書=**DV/OV/EV**。**Let's Encrypt(ISRG)はDVのみ・無料・自動更新**。一元管理先=エンハンスドLB/ウェブアクセラレータ。
- ディスク暗号化=**新規作成時のみ有効化・後変更不可・IOPS影響なし**、**アーカイブ/自動バックアップ不可**。オブジェクト暗号化=**バケット単位・既存対象外**。
- マルウェア対策=**OS/アプリは利用者責任**。

### 3.2.3 アプリケーションのセキュリティ
- **パケットフィルタ=ステートレス/NIC適用/無料/ログなし**、**VPNルータFW=ステートフル/境界アプライアンス/有料/ログあり（既定無効）**。
- WAF3タイプ=**ホスト型/クラウド型/境界アプライアンス**。さくらは**ホスト型WAFを無料提供**。
- DDoS=さくらが**バックボーンレベルで対応**。エンハンスドLBのVIPフェイルオーバで別VIPへ自動切替（**目安約5分**）。
- 機密情報サーバはローカルのみ、Webサーバは**NIC2つ**。配下サーバのデフォルトGW=VPNルータのプライベート側NIC。

## E. 大項目3.3 可用性・拡張性の設計

### 3.3.1 可用性 🔢
- ⚠️ **SLA: 月間サーバー稼働率 99.95%以上**。稼働率=(総稼働−累計障害)÷総稼働×100。**減額は利用者申請制**。
- 責任分界点: さくら=**HW・基盤SW・PaaS/SaaS** / 利用者=**設定変更・OS・ミドル・アプリ・データ**。
- メンテ告知: **サーバ/アプライアンスは初回おおむね1か月前**、他は2週間前。**緊急連絡用メールが1つでもあると会員IDメールに通知されない**（プロジェクト単位・最大10個）。
- リージョン間冗長=東京-石狩。**DBクラスタは3ノード/3ゾーン・2ノード障害で読み書き停止**。
- VPNルータ=**プレミアム/ハイスペックでVRRP冗長**（復旧目安15秒）。**NFSアプライアンスはシングル構成**（復旧目安10〜15分）。**DBアプライアンス切替約30秒**。

### 3.3.2 拡張性 🔢
- 上限値: プロジェクト**3個/会員ID**、メモリ**300GB**・ディスク**20TB**（各プロジェクト×ゾーン合計）、自動バックアップ**5設定**。引き上げはサポートへ依頼。
- 制限値: サーバ接続ディスク**最大3個**、アーカイブ**最大1TB**、パケットフィルタ**30個**。スイッチ接続推奨**200台程度**、**タグVLAN不可**。
- オートスケール: トリガー=**CPU TIME or ルータ＋スイッチのトラフィック**、**監視10分間隔**。垂直=スペック / 水平=台数。
- ⚠️ スケールインで**サーバ・ディスク削除→ステートレス構成**（外部DB/NFSに外出し）が必須。
- オブジェクトストレージ: 1バケット**10TiB**、1プロジェクト**20バケット**、標準最大**200TiB**。

## F. 大項目3.4 コストパフォーマンス設計

### 3.4.1 コスト設計（料金体系）🔢
- 料金=**従量課金（最小1時間・1時間未満は切り上げ）** と **月額料金制**。
- ⚠️ **10時間分の時間割=1日分の日割 / 20日分の日割=1か月分の月額**。**20日以上利用で月額適用**（利用時間に応じ最安が適用）。
- サーバ=**起動時間の総和**、ディスク=**作成〜削除の期間**で課金。
- DB停止時非課金: **冗長化なし/リードレプリカ かつ 2024/9/26以降作成**が対象。
- ⚠️ ライセンス: **Datacenter Edition=従量 / リモートデスクトップ系=月額**。**ルータ＋スイッチ=従量 / プリフィックス=月額**。
- 支払い=原則クレカ後払い、**1回1,000万円以上は銀行振込**、**プリペイドは法人のみ**。
- 料金アラート=**無料**、通知先**メール/Slack/Discord**。**割引パスポート**=12/24/36ヶ月、対象=通常プラン/専有ホスト/VPNルータ/LB/OSアーカイブプラン、**対象外=コア専有・ディスク・Windowsライセンス**。**クラウドクーポンは16桁**。

### 3.4.2 コンピューティングのコスト
- 基本=**スモールスタート**。最安ゾーン=**石狩第1/第3**。**コア専有(EPYC9004)=東京第2・石狩第3のみ / 高火力VRT=石狩第1のみ**。
- **steal**（共用ホストのCPU処理待ち）が許容できなければ**コア専有 or 専有ホスト**。メモリは常に専有割当。
- 専有ホスト=**契約時点から課金・0台でも課金・上のサーバ起動時間は対象外**。
- ⚠️ さくらのクラウドに**スケジュール自動停止/起動機能はない**→API実装。**usacloud=手続き型CLI / Terraform=宣言型(HashiCorp)**。

### 3.4.3 ストレージのコスト
- 標準=HDDの2倍以上 / SSD=HDDの20倍以上の性能目安。標準プランのサイズは**ゾーンで異なる**（東京第2・石狩第3は2TB〜）。
- アーカイブは**ディスクより安価・ライセンス料金なし**。自動バックアップは**アーカイブ料金＋処理実行料金**。対象ディスク**最大1TB**。
- CRRは機能/転送は無料だが**ディスティネーションバケット料金＋バージョニング課金**。オブジェクトストレージ**アーカイブプランはアクセス数が標準の1/10**。

### 3.4.4 ネットワークのコスト
- ⚠️ 原則**データ転送量の従量課金なし**（例外: **AWS接続オプションは双方向で転送量課金＋ローカルルータ必須**）。
- 共有セグメント=**100Mbps共有・無料**。ルータ＋スイッチ=**日割なし・時間割合算・1時間未満切り上げ・プラン変更で停止なし**。
- オートスケール発動後**最低1時間維持**（`cooldown=3600`）、予測可能なら**スケジュール機能**。
- **GSLBには性能別プランがない**。1台のLBに実サーバ**最大40台**（超過はGSLB＋LB多段）。エンハンスドLBのトリガーは**CPU時間 or トラフィックのみ（コネクション数不可）**。

### 3.4.5 データベースのコスト
- 評価軸=**CPUコア/メモリ/ディスクI/O**。リソース不足は**トランザクション失敗→不整合**。
- アプライアンス=**OS/ミドル不要・エンジン/ゾーン問わず料金同一・スイッチ接続必要**。**リードレプリカは1台ごとにマスター同等料金**。バックアップ無料（NFS保管は別料金）。
- ⚠️ アプライアンスのプラン変更=**停止→新規作成、旧機は自動削除されず手動削除**。
- ハイブリッド: **専用サーバPHY=ブリッジ経由 / ハウジング=ハイブリッド接続経由**。

## G. ひっかけ注意リスト（最終確認）
- リージョン＝地理的単位（配置不可）／ゾーン＝NW管理単位（配置可）。同一リージョンのゾーン分散はDR非推奨。
- VPS=スケールアウト不可・月額のみ・物理障害で停止。クラウドとの違いは**可用性**。
- 負荷分散: LB=**L4/DSR/40台/IPv6×**、GSLB=**DNS相当/12台/IPv6○/TTL10秒**、エンハンスド=**L7/プロキシ/HTTPSはCPS1/10**。
- GSLB/エンハンスドは**ローカルIPを実サーバ登録不可**。
- 使用可能IP=**追加IP−5**。10Gbpsは**東京第2のみ**。
- DB: **冗長化オプションとリードレプリカは併用不可**、クラスタは**3ゾーンマルチマスター**、Oracle不可、共有セグメント不可。
- 継続的バックアップは**NFS必須・冗長化構成では不可**。自動バックアップは**最大10世代・1TBまで・曜日指定のみ**。
- **2要素認証は会員IDログインで必須**。IAM=リソース制御 / ID=ユーザ制御。操作4段階の包含関係。
- ディスク暗号化は**新規作成時のみ・アーカイブ/自動バックアップ不可**。Let's EncryptはDVのみ。
- **SLA=99.95%・減額は申請制**。NFSはシングル構成。DBクラスタ2ノード障害で読み書き停止。
- オートスケール=**CPU TIME or ルータ＋スイッチのトラフィック・10分間隔**。スケールインに備え**ステートレス構成**。
- 課金: **20日以上で月額適用**。ルータ＋スイッチ=従量/プリフィックス=月額。Datacenter=従量/RDS系=月額。
- **データ転送量の従量課金なし**（例外: AWS接続オプション）。割引パスポート対象外=**コア専有・ディスク・Windowsライセンス**。
- スケジュール自動停止/起動機能は**ない**（API実装）。
