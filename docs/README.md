# さくらのクラウド検定 アドバンスド 試験対策ドキュメント

さくらのクラウド検定アドバンスド（SCA）教材 全11冊・計487ページを解析し、模擬試験で参照できるよう要点を整理した試験対策ノート集です。

> 出典: さくらインターネット株式会社「さくらのクラウド検定アドバンスド」教材（CC BY-SA 4.0）。本ノートは学習目的の要約です。仕様・数値は教材本文を逐語的に保持していますが、最終的な正確性は公式ドキュメントもご確認ください。

## 使い方
- **試験直前** → [`00_暗記チートシート.md`](00_暗記チートシート.md)（全体横断の最重要ポイント・数値・比較表だけを凝縮）

## 学習の全体像（5 STEP）
1. **STEP1 アプリケーション基盤の高度化** … コンテナ（1.1.1）、アプリ連携（1.1.2）
2. **STEP2 データベース** … 分散DB / NoSQL（1.2.1）
3. **STEP3 コンテンツ配信** … CDN（1.3.1）
4. **STEP4 クラウドの運用管理** … モニタリング（1.4.1）
5. **STEP5 セキュリティとガバナンス** … 暗号化（1.5.1）、ガバナンス（1.5.2）

→ これら要素技術を踏まえ、Part 2 で規模別の最適設計（小・中・大）を学ぶ。
