2. **STEP2 データベース** … 分散DB / NoSQL（1.2.1）
3. **STEP3 コンテンツ配信** … CDN（1.3.1）
4. **STEP4 クラウドの運用管理** … モニタリング（1.4.1）
5. **STEP5 セキュリティとガバナンス** … 暗号化（1.5.1）、ガバナンス（1.5.2）
